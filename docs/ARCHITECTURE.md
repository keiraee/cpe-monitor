# CPE Monitor - 技术架构文档

## 系统架构

```
┌─────────────────────────────────────────────────┐
│                  用户浏览器                       │
│  ┌─────────────────────────────────────────────┐ │
│  │           前端 (index.html)                  │ │
│  │  - HTML5 + CSS3 + Vanilla JS                │ │
│  │  - Fetch API 轮询（失败指数退避）            │ │
│  │  - 响应式布局                               │ │
│  └──────────────────┬──────────────────────────┘ │
└─────────────────────┼───────────────────────────┘
                      │ HTTP GET /cgi-bin/cmonitor
                      ▼
┌─────────────────────────────────────────────────┐
│              ImmortalWrt (CPE)                   │
│  ┌─────────────────────────────────────────────┐ │
│  │           uhttpd (Web 服务器)                │ │
│  │  - 端口 80/443                              │ │
│  │  - CGI 支持                                 │ │
│  └──────────────────┬──────────────────────────┘ │
│                     │                            │
│  ┌──────────────────▼──────────────────────────┐ │
│  │         CGI 脚本 (cmonitor)                  │ │
│  │  - Shell 脚本                               │ │
│  │  - 采集系统数据                             │ │
│  │  - 输出 JSON                                │ │
│  └──────────────────┬──────────────────────────┘ │
│                     │                            │
│  ┌──────────────────▼──────────────────────────┐ │
│  │           系统数据源                         │ │
│  │  - /proc/meminfo、/proc/uptime、/proc/loadavg │ │
│  │  - /tmp/dhcp.leases (DHCP 租约)             │ │
│  │  - iwinfo (WiFi 客户端)                     │ │
│  │  - ubus (系统服务)                          │ │
│  └─────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────┘
```

## 数据流

```
浏览器 ──HTTP GET──> uhttpd ──CGI──> cmonitor
                                         │
                                         ▼
                                    读取系统数据
                                         │
                                         ▼
                                    生成 JSON
                                         │
                                         ▼
浏览器 <──JSON 响应── uhttpd <──stdout── cmonitor
```

## 前端架构

### 模块划分

```
index.html
├── CSS
│   ├── 变量定义（颜色、间距）
│   ├── 全局样式
│   ├── 组件样式
│   └── 响应式断点
└── JavaScript
    ├── DataManager（数据获取）
    ├── UIManager（界面更新）
    ├── ConfigManager（配置管理）
    └── App（主控制器）
```

### 刷新机制

- 默认 5 秒自动刷新
- 支持配置刷新间隔（1s/3s/5s/10s/30s）
- 页面不可见时暂停刷新（节省资源）
- 进行中的请求会合并；刷新不会被丢弃
- 网络错误时按间隔指数退避重试，上限 30 秒

## 资源占用估算

| 组件 | 内存占用 | CPU 占用 |
|------|---------|---------|
| CGI 脚本（单次执行） | ~100KB | < 1% |
| 前端页面 | ~500KB | < 0.5% |
| uhttpd（已有） | 不额外占用 | - |
| **总计** | **< 1MB** | **< 1.5%** |

## 安全考虑

1. 仅监听局域网接口
2. 无用户认证（局域网信任模型）
3. 不暴露敏感信息（如密码、密钥）
4. 使用 HTTPS（可选）
5. 前端对主机名/SSID 等字段做 HTML 转义
6. CGI 对 JSON 字符串转义；临时文件使用 PID 隔离
7. 页面不依赖外网字体，WAN 断开时仍可打开
