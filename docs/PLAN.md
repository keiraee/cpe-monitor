# CPE Monitor - 智能CPE监控面板

## 项目概述

为 Nradio C8-660 CPE 设备开发一个轻量级 Web 监控面板，运行在 ImmortalWrt 系统上，实时展示设备状态和连接客户端信息。

## 目标用户

- 网络管理员 / 设备运维人员
- 需要快速查看 CPE 连接状态的用户

## 核心功能

### 1. 系统监控
- 设备运行时间
- CPU 负载
- 内存使用情况
- 存储空间使用情况
- 网络连接数（conntrack）

### 2. 网络监控
- 已连接设备列表（DHCP 租约）
- WiFi 客户端连接状态
- WiFi 网络信息（SSID、信道、模式）
- 设备信号强度

### 3. 实时刷新
- 支持自动刷新（可配置间隔）
- 支持手动刷新

## 技术选型

### 前端
- 纯 HTML/CSS/JavaScript（无框架依赖）
- 响应式设计，支持移动端访问
- 使用 CSS Grid/Flexbox 布局

### 后端
- Shell CGI 脚本（极低资源占用）
- 无需额外安装依赖
- 利用 OpenWrt 内置工具（jsonfilter、iwinfo、ubus）

### 数据格式
- JSON 格式传输
- RESTful 风格接口

## 约束条件

1. **资源占用极低** - CPE 设备内存有限（491MB），必须轻量
2. **无额外依赖** - 不能安装额外软件包，使用系统内置工具
3. **兼容性** - 兼容 ImmortalWrt 21.02
4. **安全性** - 仅局域网访问，不暴露到公网

## 验收标准

1. 页面加载时间 < 2 秒
2. 数据刷新延迟 < 1 秒
3. 内存占用 < 5MB
4. 支持主流浏览器（Chrome、Firefox、Safari、Edge）
5. 移动端可用
